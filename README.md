# websites

A workspace for building websites. Each site lives in its own folder under `sites/`.

## Layout

```
sites/    one folder per website (each self-contained, own package.json)
shared/   assets and snippets reused across sites
docs/     ideas, briefs, and design notes
```

## Starting a new site

1. Write a short brief in `docs/<site-name>.md` (goal, audience, pages, style).
2. Scaffold the site in `sites/<site-name>/`.
3. Run it locally and iterate.

## Requirements

Node 20+ and npm.
